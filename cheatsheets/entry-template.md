# Portfolio Entry Template

**Date:** 2026-08-15
**Source:** Assignment U1-01 — Example Entry
**Environment:** GitHub web interface

## Goal
Document and reflect on a completed cybersecurity assignment or lab exercise.

## Steps
1. Complete the assigned task or lab
2. Document each command or step taken
3. Record the output and results
4. Note any deviations from expected behavior

## Findings
- What worked as expected
- What was surprising or unexpected
- Skills or concepts reinforced by this exercise
- How this connects to broader cybersecurity principles

## Issues and how I resolved them
- List any errors, blockers, or confusion encountered
- Describe the troubleshooting steps taken
- Explain how the issue was ultimately resolved
- If no issues occurred, note: "No issues this time."

## References
- Official documentation links
- Course materials or textbooks
- Related write-ups or tutorials
- Tools or commands used
